# MathPath — интерактивный тренажёр линейных уравнений

MathPath помогает школьникам решать линейные уравнения по шагам и сравнивать две стратегии обучения на одном сценарии: **2(x + 3) = 14**.

- **Стратегия A (последовательная):** при ошибке ученик остаётся на этапе и получает подсказку.
- **Стратегия B (адаптивная):** при ошибке ученик переходит на дополнительный этап «Обратные действия» и после успеха возвращается к основному маршруту.

Симуляция ошибки: на этапе 2 автоматически вводится `20` вместо `8` (14 + 6 вместо 14 − 6). При одинаковых данных стратегии дают разные маршруты — это можно проверить вручную и автоматическим прогоном на странице «Сравнение».

## Запуск

Требуется Node.js 18+.

```bash
npm install
npm run dev      # разработка
npm run build    # production-сборка в dist/
npm run preview  # предпросмотр сборки
```

## Публикация на GitVerse Pages

1. Соберите проект: `npm run build`.
2. Загрузите содержимое папки `dist/` в репозиторий GitVerse Pages (ветка/папка, настроенная как источник Pages).
3. Откройте опубликованную страницу — регистрация и сервер не требуются.

Сайт — статическое приложение (React + Vite + Tailwind CSS), работает без платных API и внешних сервисов. Статистика и прогресс хранятся в LocalStorage; если LocalStorage недоступен, сайт продолжает работу с предупреждением и временной памятью.

## Структура

- `src/App.tsx` — интерфейс: главная, обучение, сравнение, результаты.
- `src/lib/engine.ts` — учебная логика: этапы, проверка ответов, маршрутизация A/B, хранилище.
- `research/comparison.md` — документация сравнения стратегий с конкретными входными данными.
- `index.html` — точка входа.

## Контрольный сценарий

1. Стратегия A, симуляция выключена: пройти этапы `6 → 8 → 4 → 14`.
2. Стратегия A, симуляция включена: на этапе 2 вводится `20` — задержка на этапе 2 с подсказкой.
3. Стратегия B, симуляция включена: после `20` — переход на доп. этап, задание `14 − 6 = 8`, возврат к этапу 2 и завершение.

Галочки выполнения отображаются на главной странице и на странице «Сравнение».
