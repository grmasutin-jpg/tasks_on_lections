# MathPath — интерактивный тренажёр линейных уравнений

MathPath помогает школьникам решать линейные уравнения пошагово. Сайт сравнивает две стратегии обучения на одном и том же сценарии:

- **Стратегия A — последовательное обучение.** При ошибке — подсказка и повтор текущего этапа.
- **Стратегия B — адаптивное обучение.** При ошибке система определяет неусвоенное правило, открывает короткое объяснение с двумя дополнительными заданиями и возвращает ученика к исходной задаче.

Учебный сценарий: **2(x + 3) = 14**. Ошибка для симуляции на этапе 2: **2x = 20** (вместо 2x = 8).

## Возможности

- Главная страница с описанием проекта, учебным сценарием и двумя стратегиями.
- Страница обучения: текущее задание, шаги, поле ответа с клавиатурой символов, проверка, индикатор прогресса, подсказки, переключатель симуляции ошибки, журнал маршрута.
- Страница сравнения: два маршрута рядом, пройденные и текущие этапы, ошибки, дополнительные задания, итоговый статус; кнопка автоматического запуска обеих стратегий и контрольный сценарий из 7 проверок.
- Страница результатов: итоги, таблица сравнения, маршруты, история завершённых прохождений, кнопка повторного прохождения.
- Реальная проверка математики: собственный парсер линейных выражений (без `eval`), проверка эквивалентности равенств, проверка подстановки.
- Обработка ошибок: пустой ввод, буквы вместо чисел, двойное нажатие, несколько неверных попыток подряд, обновление страницы во время прохождения (прогресс восстанавливается), попытка открыть недоступный этап, неверное дополнительное задание, недоступный LocalStorage (предупреждение, сайт продолжает работать).
- Прогресс и статистика сохраняются в `localStorage` (ключ `mathpath:v1`).
- Адаптивная вёрстка для телефонов и компьютеров.

Подробное описание эксперимента: [`research/comparison.md`](research/comparison.md).

## Технологии

React 19, TypeScript, Vite 7, Tailwind CSS 4. Сборка в один HTML-файл (`vite-plugin-singlefile`). Никаких внешних API, баз данных, регистрации и серверной части.

## Запуск

Требуется Node.js 18+.

```bash
npm install
npm run dev       # режим разработки, откроется http://localhost:5173
```

## Сборка

```bash
npm run build     # результат: dist/index.html (один самодостаточный файл)
npm run preview   # локальный просмотр собранной версии
```

## Публикация на GitVerse Pages

Сайт статический, маршрутизация выполняется по хешу (`#/learn`, `#/compare`, `#/results`), поэтому сервер не нужен и обновление страницы не ломает навигацию.

1. Выполните `npm run build`.
2. Загрузите содержимое папки `dist/` (файл `index.html`) в репозиторий GitVerse Pages, либо опубликуйте папку `dist` через настройки Pages.
3. Откройте выданный адрес сайта. Все ресурсы встроены в `index.html`, внешних запросов нет.

## Воспроизведение контрольного сценария

1. Откройте **Обучение**, выберите стратегию A, выключите симуляцию и пройдите все этапы верно.
2. Включите симуляцию: на этапе 2 поле заполнено `2x = 20`. Нажмите «Проверить» — стратегия A покажет ошибку и подсказку и оставит вас на этапе 2.
3. Выберите стратегию B (симуляция включена), на этапе 2 нажмите «Проверить» — откроется дополнительный этап «Обратные действия».
4. Решите задания `6` и `x = 5`, затем вернитесь к этапу 2 и введите `2x = 8`.
5. Откройте **Сравнение** и нажмите «Контрольный сценарий» — все 7 проверок выполняются автоматически на одинаковых данных.

## Структура проекта

```
src/
  lib/
    math.ts        парсер и проверка линейных выражений и равенств
    scenario.ts    уравнение, основные этапы, дополнительные модули
    engine.ts      движок стратегий A и B, проверка ответов, автопрогоны, сводки
    storage.ts     безопасная работа с localStorage
  hooks/
    useMathPath.ts состояние приложения и сохранение
    useRoute.ts    маршрутизация по хешу
  components/      Layout, UI-компоненты
  pages/           Home, Learn, Compare, Results
  App.tsx          точка входа приложения
  index.css        стили и анимации
research/comparison.md  описание сравнения стратегий
```
